# Currency Tracker (USD to TJS)

Простой пет-проект на Python для отслеживания курса доллара США к таджикскому сомони. Скрипт парсит актуальные данные с сайта, выводит их в консоль и сохраняет всю историю в локальную базу данных SQLite.

## Что уже сделано:
- Написан парсер (`parser.py`) с использованием `requests` и `BeautifulSoup`.
- Добавлена поддержка сохранения данных в базу (`currency_tracker.db`) с помощью `sqlite3`.
- Автоматически сохраняется точное время каждой проверки курса.

## Используемые технологии:
- Python 3.11
- Requests
- BeautifulSoup4
- SQLite3
